Download Ruach

No app store needed. Install it straight from this page.

Open Ruach and install Open on the web
Android (Chrome)
  1. Tap Open Ruach and install above.
  2. In Ruach, tap the menu, then Settings, then Install Ruach on this device.
  3. Or open the Chrome menu ⋮ and tap Install app.
iPhone (Safari)
  1. Tap Open Ruach and install in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen.
