# Highnestbird website

One file: `index.html`. Double-click it to preview in your browser (no npm needed).
This folder is separate from the Ruach app folder. Never copy this index.html into the app.

## Put it online free with GitHub Pages
1. Create a new GitHub repository named `highnestbird-site` and upload this folder's files.
2. On GitHub: Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Your site appears at https://YOUR-USERNAME.github.io/highnestbird-site/
4. A custom domain (like highnestbird.com) costs money each year. Add it later under Settings > Pages > Custom domain.

The "Open Ruach" buttons point to https://ruach-highnestbird.web.app/ (the live Ruach app on Firebase Hosting).
